# Formulário SiBi/UFPR

Interface local para preencher e baixar, em PDF A4, a ficha de incorporação de materiais bibliográficos.

## Como usar

1. Abra `index.html` com duplo clique.
2. Preencha os cinco campos e clique em **Gerar PDF**.

O gerador roda totalmente no navegador e não envia os dados para a internet.
